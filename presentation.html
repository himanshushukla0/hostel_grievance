🎯 Problem Statement & Solution

Why Traditional Hostels Fail Students

Moving away from lost paper registers, unaccountable maintenance delays, unverified gate passes, and disconnected warden offices.

❌

Traditional Pain Points

  • Complaints logged on paper registers get lost with zero visibility.
  • No SLA tracking — urgent plumbing/electrical issues take weeks.
  • Gate passes forged on paper slips with no verification mechanism.
  • Mess feedback ignored; repeated food quality issues go unnoticed.
  • Visitors entered manually with zero accountability or check-out times.
✅

The Digital Solution

  • Live Ticket Lifecycle: Pending → In Progress → Resolved + Student Feedback.
  • SLA Aging Monitor: Automatic priority escalation for overdue tickets.
  • Digital QR Gate Pass: High-security QR code verified at security gate.
  • Daily Mess Pulse: Real-time ratings and keyword analysis for kitchen audits.
  • Visitor Check-in Log: Strict timestamp tracking for campus security.

☁️ Tier 2: Supabase (PostgreSQL Cloud)

Cloud Single Source

When SUPABASE_URL and SUPABASE_KEY are provided in secrets or environment, the application dynamically switches to Supabase PostgreSQL:

🔹 Centralized Cloud DB: Multi-hostel campus operations across buildings.
🔹 Storage Bucket (grievance-photos): Secure object storage for complaint photos with MIME-type verification.
🔹 Fail-Safe Fallback: If network or cloud API fails, the system automatically logs a warning and falls back to local SQLite.
💡 Zero configuration needed for offline local deployment!

🔒 Security & Offline QR Pass

Bulletproof Gate Pass & Visitor Security

Preventing forged paper gate passes and unrecorded campus exits with instant offline cryptographic QR codes.

🔏

Unguessable Code

Gate pass codes use cryptographically secure tokens (GP-2026-XXXXXX) generated only upon warden sign-off. Cannot be guessed by altering student IDs.

📡

100% Offline Scannable

Gate officers can scan the QR code with any handheld barcode scanner or phone camera even if the campus Wi-Fi or internet connection is down.

🔁

Return Check-In Logging

Security marks "Student Returned" at the gate with a single click. System flags overdue students who have not checked in past their return date.

Sidebar Gate Verifier: Gate officers don't need warden privileges — dedicated sidebar expander allows instant verification of passes and visitors.

🛡️ Privacy & Compliance

Enterprise Security & Data Protection

Built following modern application security standards to prevent data leaks, unauthorized access, and malicious inputs.

🔒 Student Privacy Protections

  • Phone Number Masking: Student and parent phones are displayed masked (e.g. +91 900****567) on public views and CSV exports.
  • Dual-Key Room Verification: Room + Student Name matching required to view tickets, preventing casual snooping of other rooms.
  • Gate Pass Shield: Full digital gate pass only unlocked when exact secret Leave Ticket ID is provided.

🛡️ Injection & Threat Prevention

  • SQL Injection Shield: All database queries use parameterized prepared statements; search queries sanitized against special chars.
  • XSS Prevention: All user-entered titles, descriptions, and notices are strictly sanitized with HTML escaping before rendering.
  • Magic-Byte Image Validation: Uploaded photos verified against PNG/JPEG binary magic bytes, blocking executable payload uploads.
